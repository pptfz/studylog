GitHub 同步配置
数据以 JSON 文件保存在你自己的 GitHub 仓库里，任何电脑填同一套配置即可看到并续写全部记录。令牌只存在本机浏览器，不会写进页面。
令牌获取：GitHub → Settings → Developer settings → Fine-grained personal access tokens → 新建，仓库范围选你的数据仓库，权限勾选 Contents: Read and write。另一台电脑：用浏览器打开本页面，填入同样的用户名 / 仓库 / 令牌，之前所有记录立即出现，之后约每 30 秒自动同步。
登录与安全
默认访客只读浏览。推荐「设置登录密码 + 开启两步验证」——密码会把令牌加密存进仓库，之后任何设备都能用密码+动态码登录；也可随时改用令牌登录。
